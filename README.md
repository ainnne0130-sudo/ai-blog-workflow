# AI Blog Automation Workflow

## Overview

This project contains an AI-powered blog automation workflow created using n8n.

The workflow automates the blog creation process from initial requirements to the final improved blog.

## Workflow

Input Requirements
→ AI Research
→ Blog Outline
→ Blog Generation
→ SEO & Content Review
→ AI Improvement
→ Final Blog

## Tools Used

- n8n
- OpenAI GPT-5-mini
- GitHub
- ClickUp

## Test Topic

The Role of AI in Manufacturing: Benefits, Applications and Challenges

## Target Keyword

AI in manufacturing

## Target Audience

General business and technology readers

## Word Count

1200–1500 words

## Workflow Features

- AI-based topic research
- Blog outline generation
- Complete blog generation
- SEO and content review
- AI-based content improvement
- Final blog output
